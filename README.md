The program sends one invented English word, lockdoubt, with its one-line definition, as the whole entry and nothing else. It writes the single line `lockdoubt: the doubt, halfway to the car, that you did not lock the door.` to `entry.txt` in the output directory.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
